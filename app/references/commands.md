# wx 全部命令与参数

通用：`--max N` 输出上限（字，默认 6000）；`--full` 不截断；`--account` 多账号时指定。

时间写法（--since/--until/--around）：`30m` `2h` `3d` `1w` / `14:00` / `10-17` / `"10-17 14:00"` / `2026-10-17` / `今天` `昨天` `前天` `本周` `本月`。只写日期的 --until 算到那天 24 点。

## wx sns-media（别名 snsimg）
下载朋友圈图片/视频到本地并自动解密（图直接 Read 看）。密钥全自动，都在动态 XML 里，不用人工找 key。

- `<who>（可省）` 名字，或 `tid:<数字>`（负号 tid 必须用 `tid:` 前缀，否则被 argparse 当成参数）
- `--tid` 指定一条动态的 tid（等价于 `tid:` 前缀）
- `--since` / `--until` 时间范围（同上）
- `-n` 最多几条动态（默认 10）
- `--kind` `image` / `video`，可逗号组合，默认 `image`
- `--thumb` 只取缩略图（快、小）
- `--force` 忽略缓存重新下载
- `--wx-ua` 下载视频时用微信 UA（视频 CDN 需要；默认已由 `sns_video_ua` 开启）
- `--backfill` 批量回填：扫描时间范围内所有动态，图片+视频一次性全下载解密进缓存（限速 0.5s/个），结束打印成功/过期/失败条数。例：`wx sns-media --backfill --since 60d`
- `--json` 结构化输出给脚本用
- 缓存目录 `~/.wxdb/<账号>/sns_media/<tid>/<i>.jpg|_video.mp4|_thumb.jpg`；过期链接显示 `[已过期 404]`，不中断整批
